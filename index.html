Number Conversion System

1. Decimal Number System

The Decimal Number System uses 10 digits (0-9) and has a base of 10.

Examples: 25, 347

2. Binary Number System

The Binary Number System uses only 0 and 1 and has a base of 2.

Examples: 1010₂ = 10₁₀, 1111₂ = 15₁₀

3. Octal Number System

The Octal Number System uses digits 0-7 and has a base of 8.

Examples: 17₈ = 15₁₀, 25₈ = 21₁₀

4. Hexadecimal Number System

The Hexadecimal Number System uses 0-9 and A-F and has a base of 16.

Examples: A₁₆ = 10₁₀, 1F₁₆ = 31₁₀
